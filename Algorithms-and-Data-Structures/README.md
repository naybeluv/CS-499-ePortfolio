# Algorithms and Data Structures

## Enhancement Two: Work Order Prioritization

For this enhancement, I improved the Business Operations Management System by adding an algorithm to prioritize active work orders based on their priority level and how long they have been open.

I used a WorkOrder object and an ArrayList to organize the work orders. I also implemented a merge sort algorithm to display higher-priority work orders first, using the number of days open as a tie-breaker.

This enhancement demonstrates my ability to apply algorithms and data structures to solve a practical business problem.
